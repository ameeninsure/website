# Ameen Insurance Website

A modern, multilingual website for Ameen Insurance Broker built with Astro.

## 🌍 Languages

- English (default)
- Arabic (RTL support)

## 🚀 Features

- **Multilingual Support**: Full English and Arabic translations
- **RTL Support**: Proper right-to-left layout for Arabic
- **Responsive Design**: Mobile-first approach
- **Modern UI**: Clean and professional design
- **Fast Performance**: Built with Astro for optimal speed
- **SEO Optimized**: Proper meta tags and structure

## 🛠️ Tech Stack

- **Framework**: Astro 5.x
- **Internationalization**: astro-i18next + i18next
- **Styling**: Native CSS with CSS Variables
- **Fonts**: Inter (English), Tajawal (Arabic)

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd ameen-website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit:
- English: `http://localhost:4321/`
- Arabic: `http://localhost:4321/ar/`

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run astro` - Run Astro CLI commands

## 🎨 Customization

### Colors

Edit the CSS variables in src/layouts/Layout.astro

### Translations

Update translation files in public/locales/
